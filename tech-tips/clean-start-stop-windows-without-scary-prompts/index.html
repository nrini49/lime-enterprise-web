Clean start and stop: how to run Windows trading helpers without scary prompts

From me, Rosie: I'd much rather start quietly than greet you with an alarming question. Here's what that PowerShell prompt is, and how to start and stop me without it.

What the prompt means

Execution Policy Change
The execution policy helps protect you from scripts that you do not trust. ...
Do you want to change the execution policy?
[Y] Yes  [A] Yes to All  [N] No  [L] No to All  [S] Suspend  [?] Help (default is "N"):

In plain words: Windows is asking whether to change the rule that decides which PowerShell scripts are allowed to run. Depending on how the change is made, that rule can cover the whole computer, not just one program.

The prompt appears when the Set-ExecutionPolicy command runs.

What to answer

  1. Didn't type Set-ExecutionPolicy yourself just now? Answer N, or just press Enter: N is the default.
  2. Did type it yourself? Answer Y only when you know exactly which change it makes. The one shown further down, with -Scope Process, affects only that one window.
  3. Not sure? Answer N. Nothing breaks by saying no; the script simply doesn't run.

To see the current rules without changing anything, type Get-ExecutionPolicy -List.

Start and stop with the .bat launchers

  1. Start: double-click Rosie's start launcher (the .bat file, or the desktop shortcut made from it). On Interactive Brokers, start TWS or IB Gateway first and let it finish signing in.
  2. Stop: double-click Rosie's stop launcher. It stops only Rosie. It doesn't close your broker app, and it doesn't cancel orders already at your broker.
  3. That's it. The .bat launchers don't ask to change any PowerShell rule, so there's no prompt to answer.

If a PowerShell script really must run

Use a rule that lasts only as long as one PowerShell window. It resets by itself when the window closes, and the rest of the computer is untouched.

  1. Open a new PowerShell window.
  2. Type Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass and press Enter. The prompt appears; because you typed this yourself and it says -Scope Process, answering Y changes this window only.
  3. Run the script from that same window. Only run scripts that came with Rosie, or that you know and trust.
  4. Close the window when you're done. The rule goes back to what it was.

For a single script, this one line does the same job with no prompt and no lasting change: powershell -ExecutionPolicy Bypass -File "C:\path\to\script.ps1"
